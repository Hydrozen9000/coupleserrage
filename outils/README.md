# Outils Claude Code (captures du 02/10/2026)

Les dépôts sont clonés par `./telecharger.sh` (non versionnés : 1,3 Go).

Installation (commandes trouvées dans les README des projets) :

- Plugins Claude Code : `/plugin marketplace add <owner/repo>` puis `/plugin install <nom>`
  - thedotmack/claude-mem, OthmanAdi/planning-with-files, jarrodwatts/claude-hud,
    openai/codex-plugin-cc, wshobson/agents, anthropics/claude-plugins-official
- Skills : `npx skills add JuliusBrussee/caveman -g` ; `uv tool install graphifyy && graphify install`
- ui-ux-pro-max : `npm install -g ui-ux-pro-max-cli`
- repomix : `npx repomix@latest`
- playwright-mcp : serveur MCP `npx @playwright/mcp@latest`
- vibe-kanban : `npx vibe-kanban` (projet en arrêt)
- Les autres (cc-switch, claude-code-router, multica, firecrawl, github-mcp, codegraph) : voir le README de chaque dépôt.
- Listes de référence : awesome-claude-skills, awesome-mcp-servers, system-prompts, claude-code-best-practice.
